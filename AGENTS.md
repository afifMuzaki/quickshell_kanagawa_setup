# AGENTS.md

## What this is

QuickShell (0.3.x) status bar config for Wayland — a declarative shell panel built with QML. `shell.qml` is the entrypoint; it's discovered automatically as the "default" config since it lives at `~/.config/quickshell/shell.qml`.

## Agent Rules

When running CLI/AI agents within this workspace, strictly adhere to the following rules:

1. **`quickshell` Executable Restrictions**:
   - You may only invoke `quickshell` autonomously to access its help options (e.g., `--help`) or to view manual pages (`man quickshell`).
   - Any other execution of `quickshell` (e.g., launching, listing, or killing instances) **requires explicit user approval** before running.
2. **Documentation & Reference**:
   - Utilize web search functionality whenever you need to reference Quickshell or QtQuick documentation, API specifications, or examples from online sources.
3. **Scope & Execution Efficiency**:
   - Do not perform unnecessary or scope-creeping actions unless explicitly instructed by the user (e.g., broad directory scans/searches across `root` `/` or `~` home directory).
   - Avoid executing long-running tasks, resource-intensive operations, or non-essential commands without prior confirmation.

## Run / iterate

```sh
# Launch (first instance)
quickshell

# Launch with verbose logging
quickshell --verbose

# View running instances
quickshell list

# Kill all instances (stops the bar)
quickshell kill

QuickShell **hot-reloads on file save** — no manual restart needed during development.
```

## Structure

```
shell.qml              → Scope, loads StatusBar.Bar
StatusBar/
  Bar.qml              → Variants + PanelWindow (per-screen top bar)
  BarItem.qml          → Styled pill component (hardcoded bg #16161D, text #DCD7BA)
  Clock.qml            → pragma Singleton, exposes formatted time via SystemClock
```

All QML components are loaded via **relative file imports** (e.g. `import "./BarItem.qml"`), not QML modules.

## Quirks

- **QuickShell QML ≠ standard QML.** Key types: `Scope`, `Singleton`, `PanelWindow`, `Variants`, `Quickshell.screens`, `SystemClock`. These won't resolve in a generic Qt QML LSP without `.qmlls.ini`.
- **Singletons**: `Clock.qml` uses `pragma Singleton` + `Singleton {}`. Access as `Clock.time` (property of the root object). The file must be imported in the consuming component.
- **`.qmlls.ini`** is auto-generated by quickshell. Its `buildDir` points to an ephemeral runtime VFS path (`/run/user/1000/quickshell/vfs/...`) — machine-specific and disposable. Do not commit edits to this file.
- **No linter, formatter, tests, or CI.** Verification = launch on a Wayland compositor (Hyprland, etc.) and check visual output + `quickshell --verbose` logs.
- Font: `CaskaydiaCove Nerd Font` must be installed for `BarItem` to render correctly.
